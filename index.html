Top projects

Why some counties have far more preventable hospitalizations

Stata

How much of the gap between counties traces back to economic hardship? Using the 2025 County Health Rankings (3,159 counties), I built up from a single-regressor OLS to log-transformed models with interaction terms, plus a logit model for high-hospitalization counties.

An automated pipeline tracking housing affordability across 500 metros

Python · SQL · AWS · Excel

A weekly AWS Lambda job pulls Zillow, Freddie Mac and Census data, quarantines bad records through 48 config-driven quality checks, models affordability in SQL, and publishes a dashboard via CloudFront and a downloadable Excel report.

Do big college sports wins boost applications?

Python · pandas · statsmodels · College Football Data API

A pipeline that pulls game results, betting lines, and team records, flags upsets and other high-profile wins, and fuzzy-matches school names to admissions data. Then OLS on log-transformed application counts with robust standard errors.
