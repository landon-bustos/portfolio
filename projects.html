Is WIC vendor access unequal across rural and urban California?

Python · pandas · statsmodels

We merged WIC vendor locations with county population and USDA Rural-Urban Continuum Codes, then compared vendor density across all 58 counties. With a sample that small, a bootstrap made more sense than a t-test.

Forecasting the Central African Republic's GDP and imports

R

Time series modeling of 58 years of World Bank data for an economy shaped by repeated coups and a 2013 civil war that cut GDP by about 36%. I differenced the non-stationary series and chose model orders using ACF/PACF plots and AIC.

Detecting government spending news with NLP

Python · spaCy

Can a text classifier pick out news about government spending as well as a human reader? I hand-annotated 1,000+ articles toward a 2,400+ article benchmark, then built a spaCy pipeline that combines keyword filtering, named-entity recognition, and TF-IDF.

Song popularity and recommendations from audio features

Python · PyTorch · scikit-learn · pandas

On 114,000 Spotify tracks, we predicted popularity from audio features using feature selection and cross-validation. We also built a recommender that compresses features with a neural network and finds similar songs with k-nearest neighbors.

Live institutional data dashboard

HTML · CSS · JavaScript · REST API

A custom website that pulls live data from a REST API into a self-updating dashboard used by 12 staff. I also migrated and cleaned 10,000+ records and automated recurring reports with Power Query and VBA.

San Francisco housing listings scraper

Python · Selenium · pandas

A Selenium scraper that paginates through listings in six San Francisco neighborhoods, from Sea Cliff to the Tenderloin. It handles missing fields and cleans prices, beds, and baths into an analysis-ready dataset.
